# V-Cycle Politics

**La politique devrait être vérifiable.**

V-Cycle Politics est un projet civique indépendant et open source qui explore l'application du cycle en V à la conception, au financement et à la vérification des politiques publiques.

## Principes

- partir d'un problème observable ;
- définir des objectifs mesurables avant l'action ;
- expliciter les exigences, coûts et financements ;
- vérifier les résultats de façon indépendante ;
- corriger ou supprimer les politiques qui n'atteignent pas leurs objectifs ;
- permettre aux citoyens d'exprimer leurs choix idée par idée plutôt que par packages politiques.

Le comparateur de candidats est volontairement séparé de la présentation du concept.

## Site

Le dépôt est publié automatiquement avec GitHub Pages à chaque push sur `main`.

- `/` : présentation du concept et du cycle en V ;
- `/compare/` : prototype du comparateur de candidats.

Le site est actuellement en français. La structure est prévue pour être internationalisée ultérieurement.
